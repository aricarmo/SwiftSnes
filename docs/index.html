Super Nintendo · macOS 15.4+ · Open source

O Super Nintendo que mora no notch do seu Mac.

Um painel preto se funde ao entalhe da tela. Passe o cursor para ver o título e o FPS, clique para expandir o jogo, e volte ao trabalho sem fechar nada.

GAME
60 FPS
01 — ESPIE

Cursor no notch

O cabeçalho aparece sozinho: título do jogo, FPS e estado de pausa. Nada de janela extra no Dock ou na barra de menus.

02 — JOGUE

Clique para expandir

O painel desce com o jogo em tempo real. Arraste uma ROM para dentro ou escolha uma das recentes.

03 — FIXE

⌘⇧P mantém o teclado

Atalho global captura o teclado para o jogo. Esc solta. Tudo reconfigurável no painel de ajustes.

Por dentro

Emulação completa, escrita do zero em Swift.

CPU 65C816 · PPU modos 0–7

Sprites, HDMA e todos os modos de vídeo, incluindo o Modo 7.

SPC700 + S-DSP

BRR, ADSR e echo. Áudio a 32 kHz com ring buffer lock-free, sem estalos.

LoROM · HiROM · ExHiROM

Detecção de header por pontuação. Save de SRAM automático.

DSP-1 a DSP-4

Coprocessador NEC µPD77C25 emulado. Super Mario Kart e Pilotwings rodam com o firmware que você fornece.
